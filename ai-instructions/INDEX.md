# ai-instructions index

Working notes for any AI agent picking up this project. Polished documentation lives in `docs/`.

| File | What it's for | Update when |
|---|---|---|
| `GLOBAL_CLAUDE.md` | Local, git-ignored copy of Mikkel's global rules (repo is public) | Only if he changes them |
| `CLAUDE.md` | What this project is and what must never be violated | Fundamentals change |
| `FEATURES.md` | What exists vs planned | Every session |
| `FUTURE_IDEAS.md` | Ideas parked while working on something else | As they come up |
| `WORKING_NOTES.md` | Decisions with reasons, open questions, concerns | Every session |
| `SESSIONS.md` | Chronological log of sessions | End of every session |

`docs/research.md` is the Phase 1 research synthesis (with decisions); `docs/research-notes/` holds the raw per-topic research with sources; `docs/benchmarks.md` keeps every measured number across iterations; `experiments/` holds the probe scripts that produced them.

Start here: `CLAUDE.md` → `WORKING_NOTES.md` (open decisions) → latest `SESSIONS.md` entry.
